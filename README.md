# Поиск афиш по текстовому описанию

Учебный проект по дисциплине «Проект — применение машинного обучения в креативных технологиях». Исполнитель — Мирута Александр Владиславович, группа МИК22.

Подготовлена лабораторная работа № 4 «Реестр данных и Data Card». В проекте есть воспроизводимая синтетическая коллекция афиш, реестр источников, схема, паспорт данных и протокол разделения выборок. Следующий этап предполагает сравнение поиска TF-IDF с вариантом, использующим словарь синонимов.

## Запуск

Нужен Python 3.10 или новее. Используется стандартная библиотека Python.

```bash
git clone https://github.com/LimeGoodGame/poster-search.git
cd poster-search
python3 lab-04/prepare_data.py
```

Скрипт создаёт 42 исходные записи, исключает шесть контрольных дефектов и сохраняет 36 пригодных SVG-макетов и 36 запросов. В каждой выборке — 12 карточек и 12 запросов. При запуске проверяются схема, файлы, хеши и 21 попарное пересечение. Генерируемые данные и результаты находятся в `lab-04/data/` и `lab-04/results/`.

## Происхождение и ограничения

Генератор адаптирован из [репозитория курса Irina-64](https://github.com/Irina-64/ml-creative-technologies-course/blob/844a315d71ffc11b8462308e158c24fb16253023/demo/project.py). Уведомление об авторском праве и текст MIT сохранены в [LICENSE.course](lab-04/LICENSE.course).

В локальной версии 1.1 геометрические семейства назначены разным выборкам. Все макеты и запросы синтетические. Шаблонность текстов, состав жанров и отсутствие реальных пользователей ограничивают выводы учебным каталогом. Подробности приведены в Data Card.
