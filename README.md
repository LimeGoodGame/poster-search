## Запуск

Нужен Python 3.10 или новее. Используется стандартная библиотека Python.

```bash
git clone https://github.com/LimeGoodGame/poster-search.git
cd poster-search
python3 lab-04/prepare_data.py
```

Скрипт создаёт 42 исходные записи, исключает шесть контрольных дефектов и сохраняет 36 пригодных SVG-макетов и 36 запросов. В каждой выборке — 12 карточек и 12 запросов. При запуске проверяются схема, файлы, хеши и 21 попарное пересечение. Генерируемые данные и результаты находятся в `lab-04/data/` и `lab-04/results/`.
