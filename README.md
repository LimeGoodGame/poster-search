# Поиск афиш по текстовому описанию

Учебный проект по дисциплине «Проект — применение машинного обучения в креативных технологиях». Исполнитель — Мирута Александр Владиславович, группа МИК22.

Подготовлены лабораторные работы № 4 и № 5. Проект включает воспроизводимую синтетическую коллекцию афиш, реестр источников, схему данных, разделение выборок и разведочный анализ. Следующие этапы предполагают пилот разметки и сравнение вариантов текстового поиска.

Из корня репозитория в среде с Jupyter выполните команды ниже и запустите все ячейки. Ноутбук записывает заново `quality_checks.csv` в текущую рабочую папку.

```bash
python -m pip install pandas matplotlib cairosvg
jupyter notebook lab-05/poster_eda.ipynb
```

## Запуск

Нужен Python 3.10 или новее. Используется стандартная библиотека Python.

```bash
git clone https://github.com/LimeGoodGame/poster-search.git
cd poster-search
python3 lab-04/prepare_data.py
```

Скрипт создаёт 42 исходные записи, исключает шесть контрольных дефектов и сохраняет 36 пригодных SVG-макетов и 36 запросов. В каждой выборке — 12 карточек и 12 запросов. При запуске проверяются схема, файлы, хеши и 21 попарное пересечение. Генерируемые данные и результаты находятся в `lab-04/data/` и `lab-04/results/`.
