В локальной версии данных 1.1 шесть семейств геометрии разведены между выборками. Проверка включает полный SHA-256 и SVG без текстовых узлов. Получены 42 исходные записи, 36 пригодных карточек и 36 искусственных запросов. Выполнена 21 проверка попарных пересечений. Модели в этой работе не обучались.

## Воспроизведение

Из папки `lab-04` выполнить на Python 3.10 или новее, сторонние библиотеки не требуются.

```bash
python3 prepare_data.py
```

Исходные и очищенные метаданные находятся в `data/raw.json` и `data/clean.json`. Изображения размещены в `data/posters/`. Результаты проверки и хеши сохранены в `results/audit_summary.json`, `results/exclusions.csv` и `results/split_checks.csv`. Запуск перезаписывает только генерируемые данные и результаты этой папки.
